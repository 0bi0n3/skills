# Skills folder

Add each skill in its own directory:

```text
skills/
├── README.md
└── <skill-name>/
    └── SKILL.md
```

Use a short, lowercase kebab-case directory name. Each `SKILL.md` should begin with YAML frontmatter containing at least a `name` and a concise `description`, followed by the instructions for that skill. Keep supporting files inside the skill's directory and link to them from its `SKILL.md` when needed.

The repository currently has no skills. Start from [`../templates/SKILL.md`](../templates/SKILL.md); replace the prompts with your own content before installing or publishing a skill.
